# NEXBOND product image prompts

One prompt per product, 38 in total. Each prompt is complete (the style block is already included), so copy the whole line. Every product card on the site shows its image
in a **square frame with a `#F1EFEA` warm off-white background**, so all images
should follow the same format.

## Output format (same for every image)

| Setting    | Value                                                        |
|------------|--------------------------------------------------------------|
| Aspect     | **1:1 square**, at least 1200 × 1200 px (2048 is better)     |
| Background | Plain seamless **#F1EFEA** (warm off-white). Pure white `#FFFFFF` also works |
| Framing    | Product centred and filling about 70–75% of the frame, with clear space on every side (a category label covers the bottom ~12% of each card) |
| Light      | Soft, even studio light from the top-left, with a soft contact shadow under the product |
| Save as    | PNG or JPG, using the **file name** given for each product (I'll convert them to webp) |

## Style block

This is already added to the end of every product prompt below, so the whole set looks the same. It's shown here for reference, or for any new products later:

> Professional e-commerce product photograph, square 1:1 composition, product centred
> with generous empty margin on all sides, seamless plain warm off-white background
> (hex #F1EFEA), soft diffused studio lighting from upper left, subtle soft contact
> shadow beneath the product, photorealistic, sharp focus, high detail, true-to-life
> colours, no text, no logos, no brand names, no watermark, no people, no props, no
> gradient, no busy background.

**Negative prompt** (if your tool has one):
`text, letters, words, logo, watermark, brand, label text, people, hands, clutter, props, dark background, gradient background, vignette, reflections, blurry, low resolution, cropped product, cut off edges`

> Tip: image generators garble lettering. The prompts below ask for symbols and stripes
> instead of words. If you want real wording (e.g. "CAUTION" on a tape, Arabic/English on
> a sign), add it later in Canva or Photoshop.
